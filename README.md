# Читать в своём темпе

Помогает понять, сколько страниц читать каждый день, чтобы закончить книгу к выбранному сроку.

[Открыть демо](https://mainstarkov.github.io/node-reading-pace/)

## Возможности

- Принимает число оставшихся страниц и дней.
- Округляет результат вверх до целого числа страниц.
- Выполняет расчёт в браузере сразу после нажатия кнопки.

## Скачать и запустить

**Требования.** Node.js 22+. Устанавливать пакеты не нужно.

Скачайте [ZIP исходников](https://github.com/mainstarkov/node-reading-pace/archive/refs/heads/main.zip) и откройте папку `node-reading-pace-main` **или** клонируйте репозиторий:

```sh
git clone https://github.com/mainstarkov/node-reading-pace.git
cd node-reading-pace
```

Выполните в этой папке:

```sh
node main.mjs
```

Откройте http://127.0.0.1:3000. Сервер слушает только ваш компьютер. Для порта 3001 в macOS или Linux выполните `PORT=3001 node main.mjs`. В Windows PowerShell сначала задайте `$env:PORT = '3001'`, затем выполните `node main.mjs`.

## Проверить работу

Для 240 страниц и 14 дней калькулятор покажет 18 страниц в день.

## Как устроено

`app.js` содержит расчёт. `index.html` и `style.css` описывают форму, а `main.mjs` запускает сервер.
